# Data Analysis Projects

Набор аналитических проектов, демонстрирующих применение методов анализа данных для решения бизнес-задач в области Data Scince 

## Описание проектов

| № | Проект | Описание | Инструменты |
|---|--------|----------|-------------|
| 1 | [Классификация токсичных комментариев](https://github.com/Vasiliy-124/Data-Analysis-Projects/tree/main/toxic_comment_classification) | Multi-label классификация текстов: сравнение Logistic Regression на основе TF-IDF и сверточной нейросети (1D CNN) с эмбеддингами, обученными с нуля | pandas, numpy, matplotlib, seaborn, scikit-learn, PyTorch |
| 2 | [Анализ клиентской базы](https://github.com/Vasiliy-124/Data-Analysis-Projects/tree/main/e-commerernce) | Сегментация клиентов и анализ поведенческих паттернов на основе синтетических данных e-commerce для оптимизации маркетинговых стратегий | pandas, numpy, matplotlib, seaborn, scikit-learn |
| 3 | [Статистический анализ A/B теста](https://github.com/Vasiliy-124/Data-Analysis-Projects/tree/main/AB-test) | Статистический анализ A/B теста трех промо-кампаний для выявления оптимальной стратегии увеличения продаж нового продукта | pandas, numpy, matplotlib, seaborn, SciPy, Statsmodels |
| 4 | [Анализ корзины покупок](https://github.com/Vasiliy-124/Data-Analysis-Projects/tree/main/Market_Basket_Analysis) | Анализ корзины покупок с выявлением товарных ассоциаций для повышения эффективности кросс-продаж и мерчендайзинга | pandas, numpy, matplotlib, seaborn, mlxtend |
| 5 | [Предсказание цены на автомобиль BMW](https://github.com/Vasiliy-124/Data-Analysis-Projects/tree/main/BMW_car_price) | Построение линейной модели регрессии для предсказания цены автомобиля BMW | pandas, numpy, matplotlib, seaborn, scikit-learn |
| 6 | [Кластеризация музыкальных треков](https://github.com/Vasiliy-124/Data-Analysis-Projects/tree/main/music_tracks) | Кластеризация музыкальных треков по аудиохарактеристикам алгоритмами KMeans и DBSCAN с оценкой качества | pandas, numpy, matplotlib, seaborn, scikit-learn |
| 7 | [Прогнозирование временного ряда](https://github.com/Vasiliy-124/Data-Analysis-Projects/tree/main/time_series_predict) | Прогнозирование временного ряда двумя методами: ARIMA и CatBoost с инженерией признаков | pandas, numpy, matplotlib, seaborn, statsmodels, scikit-learn, catboost |
